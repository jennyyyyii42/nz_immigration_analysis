# nz_immigration_analysis
New Zealand immigration source countries analysis using R and ggplot2

## Overview
Visualizes the top 10 immigrant source countries to New Zealand in 2023.

## Dataset
- **Source:** Stats NZ / OECD
- **Year:** 2023
- **Variable:** Number of arrivals by country

## What it does
- Creates a horizontal bar chart of top 10 source countries
- Ordered by number of arrivals
- Styled with `theme_minimal()` and custom color (`#1D9E75`)

## Tools
- R
- ggplot2
